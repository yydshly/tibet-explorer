## G318 动态预览

`g318-demo.gif` 为 2026-10-20 从[公开在线版](https://yydshly.github.io/tibet-explorer/#/routes/g318-east/whole)连续采集的实际播放画面，基于提交 `062385f`，复用现有内容；未改变运行代码、配音、镜头或场景。

- 采集起点：R02 色季拉山地讲述的 85% 位置，自动衔接 R03 鲁朗谷地；采集24秒，导出时去掉开头5秒的准备和等待。
- 内容：沿地形进入谷地、鲁朗河与道路的空间关系、林海实拍、2024 年河谷聚落实拍，再回地图。
- GIF 时长：19 秒，保持实际播放速度，未拼接不同时间的独立镜头。原始画面约每秒采集6帧，GIF 导出为4帧/秒（76帧）、720×682、128色、循环播放；缩小与色彩量化用于控制体积。
- 字幕与标注来自应用的现有配音时间轴。GIF 无音轨，不作为实际听感或全程音画同步的验收证据；有声内容请进入在线版。
- 保留界面中的照片日期、作者、许可及地图资料说明。它不是连续实地行车摄影，实拍照片也不表示当前实时景观。
