# 三站气候标准值：1991—2020

这份资料将同期观测统计与教学气流机制分开阅读。它是**站点气候标准值**，不是行政区域平均值、当日天气或旅行预报。

## 来源与取得

- 数据生产者：中国气象局国家气象信息中心（NMIC/CMA）向 WMO 提交的中国地面气候标准值。
- 公开归档：NOAA/NCEI，WMO Climatological Standard Normals 1991–2020，accession `0253808`，版本 `4.4`。
- 总说明：https://www.ncei.noaa.gov/products/wmo-climate-normals
- 原始 CSV 目录：https://www.nodc.noaa.gov/archive/arc0216/0253808/4.4/data/0-data/Region-2-WMO-Normals-9120/China/CSV/
- 读取日期：2026-10-16。原始文件按 HTTP 返回字节保存，SHA-256 见 `stations.json`。文件中的 CR/CR/LF 未改写。
- 网页检索与 NOAA 产品页面确认了该归档；网页读取工具不解析 CSV，使用 Python 标准库 `urllib.request.urlopen` 直接下载同域公开原件，没有经由百科或气候聚合网站转抄。

同目录保留 `Explanatory_Information_Region2.pdf` 和 `WMO_Normals_9120_Format_and_Parameters.pdf` 两份原始说明。中国说明见前者 PDF 第4—11页，方法说明在第9—10页。NMIC 说明数据由归档地面观测经质量控制、迁站分段处理、逐月与年值计算、标准值计算和质量评估形成；因此本产品不声称亲自重新处理30年逐日原始观测。站点迁移规则和均一性处理按提交者的方法阅读。

## 精确提取规则

运行 `node scripts/extract-climate-normals.mjs`，只从已归档的三个 CSV 读取：

1. `Parameter_Code=5, Calculation_Name=Mean, Calculation_Code=1`：日平均气温的月均值，单位 `Deg_C`。取 January—December 共12列，年值从独立 Annual 列保留，不用12个四舍五入月值重新算年值。
2. `Parameter_Code=1, Calculation_Name=Sum, Calculation_Code=4`：月累计降水量的多年均值，单位 `mm`。同样保留原 Annual 列。它包括降水，不能直接改称液态雨量或降雨天数。
3. 两参数对应 `Calculation_Name=NOY, Calculation_Code=98` 的各月与年值均为30，三站同统计期并有同年数覆盖。缺值为空列，不能转成0；提取器遇到缺值或非30年覆盖会报错。
4. 坐标由源文件度分秒按算术公式转换，保留8位小数；这些小数只保证转换可复核，不表示测量精度提高。
5. 原数以0.1度/毫米显示。图表降水采用所有月份和三站统一的0—150 mm标尺，不逐站归一化。地图柱是统计符号，不是现实水深、云层或地形高度。

## 阅读限制

- 气候标准值说明统计期的平均季节背景，不显示年际波动、极端事件或这些年份之后的变化。
- 本资料可检验一个月三站的实际差异，**不能单独识别地形、季风或城市活动的因果贡献**。机制演示与站点统计具有不同证据作用。
- 例如7月林芝站为137.4 mm，拉萨站140.5 mm，狮泉河站22.9 mm；不能让“东南更湿”的概括变成每月固定排序。7月林芝、拉萨两站月均温均为16.5°C，也不能按地区海拔印象重新生成温度。
- 1月和7月另有两段逐句读取上述站点值的 MiniMax 录音（`OBS-CLIMATE-1`、`OBS-CLIMATE-7`），同一次合成的原生词时序随各自 MP3 保存。旧机制录音没有被替换，也不能用来冒充其他月份的数值讲解。其余10个月提供文字与统计图查阅。进入观测时暂停机制；显式播放观测录音只按真实词位置强调当前站，三站数值不随朗读改变；返回后保留原机制录音与场景位置。
