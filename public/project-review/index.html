01 / 为什么做

一条认识主线，而不是地理知识目录

目标是帮助没有背景知识的人，从完整地球找到西藏，理解全球环境与高原地形怎样造成地区差异，再理解人的行动怎样形成生活、文化与历史，最后带着问题观察今天的地方。

  1. 在哪里：地球与位置
  2. 为什么：来流遇到高原
  3. 哪里不同：气候与地区
  4. 怎样生活：条件与人的行动
  5. 怎样形成和延续：历史文化
  6. 今天怎样联系：交通与观察
每次放大都要有理由，每次操作都要有结果。

整体地图 → 具体地方 → 对照变化 → 解释原因 → 回到整体。语音、文字、标注与3D使用同一讲述位置；操作时暂停，返回时恢复。

02 / 六章验收

哪些成立，哪些还主要靠讲解

“基本达标”仅表示本轮目标对应的功能与画面成立，不代表用户理解已验收。整体当前结论：暂不通过，先解决第4、5、6章的闭环。

章节结论取舍
01 地球上的西藏基本达标保留并冻结。不再加地理标签或扩展开场。
02 空气遇到高原基本达标保留并冻结现有机制，不扩展模拟精度。
03 同在西藏，为何不同基本达标保留冬夏两次对照。其他统计移入专题。
04 环境怎样进入生活部分达标只补一条生活因果链（M1）；保留三地背景，不为三地各建一套模型。
05 人怎样塑造地方未达标优先重组已有有据案例（M2），不追加零散建筑和人物。托林定位作为交流线索保留，不宣称复原古道。
06 今天怎样联系与观察部分达标冻结时长和案例，只补观察成果交接（M3），不再压录音。

基本达标

地球上的西藏

已经能做什么
已能在同一地球中区分洲、国家、自治区与自然高原；定位层级和文字对应。
差距与边界
本章以观察和尺度定位为主，不要求虚构“改变地理”的实验。仍需首次观看者确认能区分行政范围与自然范围。
收口标准
用户能指出西藏所在层级，说明西藏自治区与青藏高原不是同一范围；能回到完整地球。
这章怎么处理
保留并冻结。不再加地理标签或扩展开场。

基本达标

空气遇到高原

已经能做什么
固定气团位置0.60，切换水汽后，云雨符号明确改变，地形与高程样本保持不变；操作反馈解释冷却不必然降雨。

收口标准
同位置切换水汽得到可辨变化；用户能说出抬升、冷却、水汽的关系，并知道云雨是示意。
这章怎么处理
保留并冻结现有机制，不扩展模拟精度。

部分达标

环境怎样进入生活

已经能做什么
能切换地区、放大、改变剖面方向和移动探针；可见起伏与较缓地面。
差距与边界
当前可操作对象仍是地形。说到用水、设施、劳动与组织时，没有同等清楚的服务过程变化，城市生活的因果链尚未闭合。
收口标准
在已有地方中完成一个有资料的“条件→设施或人的行动→使用结果”案例；用户能操作对照并指出结果为什么不同。规划不得作为已建成证据。
这章怎么处理
只补一条生活因果链（M1）；保留三地背景，不为三地各建一套模型。

未达标

人怎样塑造地方

已经能做什么
已有建筑用途近景与来源定位；学习者能从观看走向练习，且明确只是学习关系示意。
差距与边界
“形成”仍以建筑用途和人物地点讲解为主；“延续”是通用功能示意。尚不能让用户看清一个具体历史事件如何改变地方空间与生活。不是完全没有动画，但动画尚未承担核心论证。
收口标准
主线中有且仅有一个完整的具名案例：真实事件→可证的空间或使用安排变化→人的活动→今天的延续；可比较、可回到全域。没有测绘就不画古城复原。
这章怎么处理
优先重组已有有据案例（M2），不追加零散建筑和人物。托林定位作为交流线索保留，不宣称复原古道。

03 / 固定问题清单

只处理这四项，再决定是否收口

处理顺序：M2历史因果 → M1生活结果 → M3观察交接 → M4理解验收。以下均为待办，本轮没有将它们标成已完成。

M1 · 必须解决 · 第4章 · 待处理

把地形条件接到生活结果

复用已有地图与资料，选一个生活服务案例，显示条件、人的投入与使用结果。证据不足的建成效果不进入主线。

怎样算完成
一个可重复的操作对照；地图、反馈和讲解指向同一结果；能说明自然条件为何不等于生活服务。
做到哪里停止
一个案例达到标准即止；不扩成三套地方模型。

M2 · 优先解决 · 第5章 · 待处理

用具体事件支撑历史变化

优先核对已有专题中的历史空间/使用调整材料，重组一个完整案例进入主线；保留来源、年份性质和推论边界。

怎样算完成
在同一地方看见有据的使用安排变化，能比较前后关系并回到全域；观众能指出谁/什么事件、改变什么、为什么影响生活。
做到哪里停止
不追求全部历史三维复原；形成与延续各自承担明确问题，禁止继续增加人物或建筑数量。

M3 · 必须解决 · 第6章收尾 · 待处理

让旅游观察真正接住主线

让现有观察计划接收一个地点、观察问题和资料来源，提供清楚的保存/编辑/返回路径。

怎样算完成
结束页两步以内生成一项可编辑的观察任务；刷新可恢复；返回仍在原章节；访问条件留待按日期核实。
做到哪里停止
不增加景区、旅游线路和预订功能。

M4 · 收口门槛 · 整场 · 待处理

做一次有终点的理解验收

M1—M3完成后，邀请3名未参与开发的观看者独立体验；每章一句解释，记录原话与误解，不由开发者代答。

怎样算完成
建议门槛：每章至少2/3人能说清对应原因和证据边界；三人均能完成一个操作并恢复讲述；不得把示意当实测、现状当古代或学习路线当行程。
做到哪里停止
只修被证实的阻断问题；只复测失败任务一轮。仍未通过就列为未通过并明确下一版本范围，不继续宣称完善。

04 / 如何停止重复迭代

从“不断加内容”改为“按门槛交付”

  1. 最初目标

    从整体到局部认识西藏，地理、气候、生活、历史文化、发展与旅游相互衔接。

  2. 已走过的弯路

    逐渐增加模型、地点、文字和标注，却把“讲到了”当作“演示清楚了”；频繁播放和局部打磨缺少结束条件。

  3. 当前基线

    六章与现有21段冻结。保留可用的气流、数据对照、桥梁和沿线观察；完整年代与扩展案例继续放在专题。本轮只新增本说明入口和验收记录。

  4. 下一轮唯一范围

    处理M1—M3，每项提供一组前后证据和一个可复现操作。资料不支持的效果删除或降为明确的原理示意，不补造历史空间。

  5. 最终门槛

    M4未做前保持“待验收”。通过后停止增加模型、案例、标签和时长调整，只处理新发现的事实错误或阻断使用的问题；新增愿望进入下一版本。

停止条件：四项都有明确结果与证据，六章能被用户解释，未解决问题被公开保留。测试通过、录音齐全、完整播放结束，都不能单独替代这个条件。
