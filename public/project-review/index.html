把你放进旅程：五个连续情境

林芝·八一城区与尼洋河谷

如果我是旅行者：我先在八一城区认识尼洋河谷，把河流、城市和山放在同一视野。决定是否先在河畔或街区走走，再沿既有道路向色季拉山地出发。

画面如何陪我走：整体线路定位 → 城市河谷斜视 → 有日期实景；图上保留出发点和前进方向。

我能选择什么：在城市河谷与随后山地的同尺度视角间比较；选择“想看河谷城市”后保留理由及出处。

色季拉山地

如果我是旅行者：我随路上山，回望刚离开的谷地。在有依据的观景位置候选处看远山方向；如果云遮住山，也能理解眼前发生了什么。随后跟着道路下到鲁朗。

画面如何陪我走：连续沿路上升 → 回望谷地 → 指向远峰方向 → 下山；已有高点仅称沿线高程样本，不能冒称实测山口或观景台。

我能选择什么：高处/谷底视角对照；远峰方向与现有地形覆盖范围分别显示。缺合格影像时远峰只保留有来源说明，不拼造可见雪峰。

鲁朗·林海、草甸与村镇

如果我是旅行者：翻山后我进入鲁朗，先看林海与谷地，再选“看风景”或“看村镇生活”。可把村镇漫步或地方风味加入计划；想了解工布新年时看有日期记录，之后回原线继续向通麦。

画面如何陪我走：沿路入谷 → 实拍辨认林地、草地、水与房屋 → 公共生活；现代小镇与传统村落分别标明，文化记录另标日期和范围。

我能选择什么：选择风景/村镇/文化关注点，画面聚焦可见对象；选择体验保留主路接入与原句位置，随时回线。

通麦·峡谷、汇流与跨越

如果我是旅行者：我随主路进入峡谷，看到路与江流如何互相贴近，在通麦辨认跨哪条江。把2014旧桥记录与后来工程分别看清，再继续沿帕隆藏布河谷前往波密。

画面如何陪我走：保持地形与原路 → 汇流俯视 → 桥江同框 → 有日期历史对照 → 回到沿路前进；不新增桥体细节或旧路复原。

我能选择什么：切换地形/道路/江流关注点；历史照片与地理位置对应，无法证明的当代景物不从旧照片推断。

波密·帕隆藏布河谷与扎木镇

如果我是旅行者：从通麦向波密前进，我先决定是否在核准的支路接入点进入森林或村落，再沿主路到扎木镇附近看县城生活。最后回看整线，把自己的停留理由和待核实条件带走；当前旅程在这里结束。

画面如何陪我走：沿帕隆藏布进入县城附近 → 有日期街景 → 整线对照；林芝城市/鲁朗村镇/波密县城同尺度比较。
