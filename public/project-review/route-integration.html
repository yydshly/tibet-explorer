同一产品，并列线路板块保持六章与原进度，线路有自己的选择、播放、地方观察与返回；共用地图和资料，按需加载细节。采用。
另起一个独立网站需要重复地图、资料、播放和计划能力，用户难以带着刚建立的认识回来。暂不采用。

资料初核：首段优先考虑林芝—色季拉山—鲁朗

G318的区域位置已有林芝市政府国道资料（页面发布2026-04-05）支持；2022年鲁朗建设报道明确讨论从林芝沿318向东经色季拉到鲁朗，并提供建设、运营与地方生活案例。林芝文旅2023-12-25的G318介绍可作风景人文线索，宣传性评价与季节描述不当作观测、访问保证或科学因果证据。

这是G318经典线路的一段候选学习体验。已有“林芝—山南—拉萨—日喀则”是认识走廊候选，不等于已经核验的一条经典公路。现有拉萨站前影像段属于青藏线，保留作底层能力参考，不能替代林芝—鲁朗或冒充拉林全线。

资料项已核对实现前仍需补齐
真实道路归档nyingchi-lulang-g318有1147个原始坐标、1146条来源边，已逐一对照OSM归档并核对单行/禁止进入标签；清单长度71971.7米，起于林芝附近道路节点，止于鲁朗服务道路。仍需确认实际观察停靠点。约72km是归档线路长度，不能当官方里程、实时导航或酒店入口。
地形已有林芝区域321×321高程覆盖全部归档线路，显示采样约0.4km；鲁朗局部257×257，约19—22m显示采样。沿山路近景仍需更精细高程或明确限定观察高度；显示采样不能冒充测量精度。
真实影像与地方外观现有区域地形和鲁朗源几何可复用。本轮未核得可覆盖整段且许可明确的精细影像/现场视角素材。不能把拉萨影像搬过来，不能用AI景观冒充当地。
风景与生态官方资料提供沿线山地、林海、季节及色季拉观察线索。现场照片的地点、方向、拍摄时间与版权；若演示植被或云雨过程，需要对应的地理或科学资料，不能给整个坡面任意染绿。
人文历史与生活已有鲁朗建设与运营报道、地方空间几何；可聚焦一项有据的小镇建设与持续运营变化。把报道支持的行动与现状空间逐项对应；旧收入/客流不能当当前统计，也不能让建筑随年份凭空增加。
进入条件与注意事项已知归档末端不是核实的访客入口。公共观察位置、访问规则、按日期核实的路况/季节信息和适当来源。本轮不作可达、许可、健康或开门承诺。

首段只实现一个完整往返

  1. 从整体看走哪段。说明G318及林芝、鲁朗的相对位置，亮出实际相连道路。
  2. 沿真实道路前进。距离进度驱动观察位置；山谷、转折与高度变化在同一地形上出现。讲到的对象有对应位置与画面。
  3. 进入一个地方。保留返回快照，从道路靠近鲁朗已有源范围，区分镇区、生活空间与未知访问入口。
  4. 做一次有原因的观察。比较同一路段的高差和视野，再用一个有据建设/运营事件解释生活变化与地方价值。复用现有几何，资料不足不补造历史场景。
  5. 回到原线。恢复原路段、距离、语句、声音条件；保存一个观察问题后也能返回。首次只交付这段，整条G318及其他支线不铺开。

实现顺序与放行条件

接入与冻结边界 → 完成首段影像/高程/观察点/历史空间资料缺口 → 独立线路播放器和返回快照 → 地方操作及逐句音画对应 → 一次首段完整往返验收。

放行标准：看见真实道路而非方向连线；能辨认两处环境变化并解释至少一个原因；能说明一个有据事件如何影响地方生活；操作和计划保存后恢复原线原句；六章录音与旧恢复记录保持。没有这些证据，不把“新入口能打开”当作首段完成。
