## 一轮怎样执行

1. 找3名此前未使用该产品的真实观看者，记录首次资格和已看内容。开发者、助手或熟悉项目的负责人不计首次；同一真实观看者可同时提供E01听感记录，无需重复安排一批人。
2. 由主持人使用独立浏览器会话或另建浏览器配置开始，避免上次进度与笔记影响初次入口；**不要清除其他人的现有记录**。仅浏览器无痕会话也须确认存储能用。
3. 确认参与意愿和取证方式，可匿名口述笔记；不自动开启麦克风、摄像头或录屏。只记必要的代号、原话、位置与操作结果。
4. 发[观看者任务单](current-participant.html)。先观看并自由叙述，之后逐章展开任务。可正常查字幕与资料、回看，不考记忆；首次回答前不提示答案。帮助、不会操作、解释不清均如实记录。
5. 完成六章及整线的7项记录，说明变化、原因和画面依据；检查实际进入、操作、计划保存刷新导出及返回。不以主持人代操作或助手技术检查替代观看者完成。
6. 至少一次由真实听验者完整有声观看六章与整线，说明实际覆盖范围，对声音清晰度、断音/重叠声、听感及语音与画面语义对应作主观记录。技术波形匹配和“播放按钮正常”不算听感通过。
7. 汇总每项真实结果；仅对具名原句、具体操作位置的关键误解、事实错误、声音错配、丢记录或返回失败重开限定修复与受影响复测。没有新证据就不改代码。
